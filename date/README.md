# 💌 Приглашение на свидание

Одностраничный сайт-приглашение: письмо с вопросом «Пойдёшь со мной на свидание?»,
кнопка «конечно 😍» и кнопка «нет 😠», которая убегает от курсора и пальца —
нажать её невозможно. После «конечно» появляется «Отлично! Я и не сомневался…»
и вся информация о свидании.

## Что поменять перед отправкой

| Что | Где |
| --- | --- |
| Дата, время, место | `config.js` |
| Тексты (письмо, план, дресс-код, P.S.) | `index.html` |
| Фотография | заменить `img/us.webp` своей (лучше вертикальной) |

Пока в `config.js` не указано место, в блоке «Куда идём?» написано «сюрприз 🤫»,
а кнопки «как добраться» нет. Если вписать название и адрес — появятся адрес
и кнопка с картой.

## Как посмотреть

Открыть `index.html` в браузере (или через Live Server в VS Code).

Чтобы сразу увидеть блок с подробностями, не отвечая на вопрос,
добавь к адресу `?yes`: `index.html?yes`.

## Как опубликовать

Сайт статический и не зависит от внешних сервисов — достаточно выложить
содержимое этой папки на любой хостинг: Netlify Drop (перетащить папку
на app.netlify.com/drop), GitHub Pages, Vercel и т. п.

Чтобы в Telegram/WhatsApp у ссылки была красивая картинка-превью,
после публикации впиши в `index.html` полный адрес картинки
в `<meta property="og:image" content="…/img/og.jpg">`.

## Файлы

- `index.html` — разметка и тексты
- `style.css` — оформление
- `app.js` — логика (убегающая кнопка, сердечки, календарь, обратный отсчёт)
- `config.js` — дата, время, место
- `fonts/` — шрифты Comforter и Montserrat (лицензия SIL OFL, см. `fonts/OFL.txt`)
- `img/` — фотография и картинка-превью
